CRM Follow-up Date
==================

Keep the next promised customer follow-up visible on every CRM opportunity and make overdue work easy to find.

Features
--------

* Next follow-up date
* Short follow-up note
* Overdue opportunity filter

Usage
-----

1. Open a CRM opportunity.
2. Set the next follow-up date and note.
3. Use Follow-up Overdue to find missed commitments.
