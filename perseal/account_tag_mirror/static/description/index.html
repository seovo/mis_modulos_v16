Marcar el campo "Tener cuenta objetivo" en la cuenta contable

Para utilizar el módulo, en la configuración de una cuenta contable debes marcar el campo "Tener cuenta objetivo". Esto habilitará los campos para seleccionar las cuentas de débito y crédito objetivo.

No se requieren configuraciones adicionales para utilizar este módulo.
Importante: Las cuentas objetivo solo pueden ser de tipo gasto o ingreso.
Si necesitas personalizaciones o tienes dudas, puedes contactarnos para soporte técnico.

Este módulo no requiere una guía de usuario específica, ya que funciona de manera automática tras su instalación.
Los usuarios del portal verán únicamente los pedidos de venta en estado 'Por Pagar' y las facturas asociadas, sin necesidad de configuración adicional.
